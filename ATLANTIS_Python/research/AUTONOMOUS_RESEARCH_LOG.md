## Entry 2. Held-out structural sampling

Hypothesis: feedback-linked sets of variables may benefit from correlated activity levels at initialization. The SCC proposal mixes equal parts uniform sampling and a guided draw. Within each nontrivial strongly connected component the guided draw samples a Beta(1/2,1/2) activation probability and conditionally independent bits. The mixture lower-bounds the probability of any permissible initial state by half its reference mass. Inputs were set to zero as an explicit test context. This context is not a measured physiological condition.

Run tools/transfer_basin_trial.py with a bnet input and a new JSON output path. The frozen design uses eight paired 32-start discovery replicates per method, a separate 1,024-start uniform audit, and a 32-transition ceiling. Every reported orbit is replayed under the source rules. Distinct orbit identifiers include every model variable. Each audit upper bound adds every unresolved trajectory to the candidate count and applies a simultaneous one-sided 95% Clopper-Pearson bound over the independently discovered candidates. This can rule in small basin mass conservatively; failing a threshold is inconclusive. Unseen attractors have no estimates.

On ErbB, the search discovered 137 distinct cycles across all replicates. Uniform versus SCC sampling found 16.375 versus 17.625 distinct cycles on average per 32 starts. The audit had 500 unresolved starts; no candidate was certified rare. Extending the audit horizon is a more relevant improvement than increasing shot count here.

On BioDiVinE 247, the first Boolean-cube run treated threshold bits as independent. This is a software stress test only. The original model is multi-valued. A follow-up run samples uniformly from ordered levels consistent with zero-valued external bits. Its guided half instead gives each extreme level three times the weight of an interior level. All permitted levels retain nonzero probability. This follow-up discovered one cycle; three of 1,024 audit starts were unresolved. The four cycles and rare-candidate result from the unconstrained Boolean cube must not be interpreted as a biological discovery. This model has 300 Boolean columns including external inputs. It does not establish a 300-distinct-gene rare attractor.

Models 252 and 263 exceeded the existing expression parser guard. They produced no benchmark outcomes. ## Entry 8. Exact tail reduction and the actual runtime bottleneck (2026-11-23)

Hypothesis: removing certified constant variables accelerates the remaining ErbB dynamics without changing basin assignment. `tools/reduced_bnet_dynamics.py` substitutes proven constants, simplifies Boolean identities and remaps surviving indices. It preserves initial-state basins by first executing the original dynamics for the seven certified settling steps. Directly projecting time-zero states is unsound: in the test A'=0, B'=A|B, initial (1,0) reaches (0,1), whereas prematurely deleting A would select B=0. Each reduced cycle is lifted, recanonicalized and replayed under the original rules. Complete fixed-point certificates bypass reduction rather than constructing an empty network.

On the all-zero, EGF-only and NRG-only ErbB contexts, reduction shrinks 247 variables to 192, 192 and 198. Rule AST sizes shrink from 8,298 nodes to 5,934, 5,980 and 6,270. The largest feedback SCC shrinks from 204 to 155, 161 and 155 respectively. These syntactic dependency SCCs need not be minimal semantic feedback components. Three fresh matched 256-start repetitions per context (seeds 820000–820002, 64-start batches) produce identical canonical full-model cycle labels for all 2,304 starts, with no unresolved cases. Original search gets 167 transitions; reduced search gets seven original settling transitions plus 160 reduced transitions. In general, resetting history at settling can change finite-horizon censoring, so equality is an observed benchmark result, not a universal finite-horizon guarantee. Eventual attractor assignment is preserved by the exact tail correspondence.

The measured original/reduced median runtime ratios are 0.973, 0.971 and 0.938, respectively: the reduced pipeline is slightly slower. Timings include reduction/certificate construction, settling, lifting and original-rule cycle replay, but exclude shared model loading and initial-state generation. Do not promote this as a runtime improvement. Raw results and repeat order: `results/erbb-reduced-dynamics-v1.json`. Four exhaustive tests check the transient counterexample and commutation of reduced steps with lifted original transitions across representative Boolean operators.

## Entry 10. Rule-compiled bounded predecessor oracle (2026-11-23)

Investigated a genuinely coherent predicate rather than another classically reproducible proposal distribution. Given a known fixed point y, mark starts x != y satisfying F^T(x)=y. `tools/rule_basin_oracle.py` compiles the existing source rules through QuantumNetwork and reversible time evolution, marks the terminal target, uncomputes all time slices and cancels the sign flip at initial state y. No enumerated basin table is used to construct the oracle. Target discovery and proof of rarity remain separate requirements; the experiment does not solve unknown-attractor discovery.

Nineteen focused tests check complete complex statevectors for one/two updates, clamp contexts, exact and relative-phase gates, target-start exclusion, 14-qubit dirty-workspace phase synthesis, non-fixed target rejection and a classical witness test that enforces both initial clamps and nontriviality. Checking amplitudes over the entire register tests phases and workspace restoration, not merely sampling probabilities. Full-size MCF-7 circuits were resource-compiled, not simulated as statevectors or run on hardware.

The chosen MCF-7 off/Nutlin target is the previously known rare fixed point 28052 with full basin size 130. After excluding that fixed point, horizons 1, 2, 4 and 8 mark 43, 116, 129 and 129 of 65,536 starts. Ideal iteration estimates using these exact diagnostic counts are 30, 18, 17 and 17, with calculated success above 99.9%. The corresponding uniform IID 95% counts are 4,565, 1,691, 1,521 and 1,521. These ideal quantum figures assume known mass and are not experimental success probabilities.

Compiled oracle sizes are respectively 32/48/80/144 qubits and 22,970/45,634/90,962/181,618 CX gates; depths are 56,062/111,224/221,438/441,866. At T=4, oracle calls alone contribute 1,546,354 CX gates over the ideal iteration count, before diffusion, initialization, routing, fault tolerance, shots or mass estimation. These are counts for the implemented compiler, not a lower bound on all quantum approaches. T=8 finds no additional starts but approximately doubles the oracle cost.

The strong classical control encodes the original integer weighted-threshold equations directly in Z3, including zero-sum ties, rather than reusing quantum ANF. It finds a non-target starting state and replays it through the original network. Encoding, solving and replay took 0.019/0.011/0.023/0.033 seconds for the four horizons in these single local runs. Each witness is stored. Oracle construction and transpilation are also timed, but no hardware runtime is inferred. No practical quantum advantage has been established, and the result does not imply impossibility of one with another construction.

The theoretical distinction between ideal query savings and procedure cost follows the primary amplitude-amplification paper, whose title and abstract were retrieved from https://arxiv.org/abs/quant-ph/0005055. Detailed scope, resource table, assumptions and reproduction are in `RULE_ORACLE_FEASIBILITY.md`. Raw results: `results/mcf7-rule-oracle-resources-v1.json`; software versions and source hashes are in the companion `.provenance.json`. All earlier artifacts were preserved.

Full regression validation: 254 tests passed with 16 warnings in 32.24 seconds. No paid compute was used. ## Entry 16. Rotation precision accounting (2026-11-24)

Audited the compiled four-step mixed MCF-7 oracle rather than equating CX reduction with physical cost. It contains 20,180 Rz operations, of which 10,156 are not multiples of pi/2 within numerical tolerance. All recorded angles lie on a pi/1024 grid to floating-point accuracy (maximum residual 1.34e-15). This is a statement about logical angle representation, not exact synthesis into a finite fault-tolerant gate set.

For each rounding grid, the audit sums |angle error|/2, using the Rz operator-norm bound and telescoping over products of unitaries. Six/eight-bit grids yield vacuous worst-case bounds for 17 oracle calls; the ten-bit grid leaves only numerical residuals. A sufficient uniform per-non-Clifford-rotation operator error for a 0.01 total oracle-only error budget over 17 calls is approximately 5.792e-8, assuming the other operations are exact. This is sufficient, not necessary, and is not a measured hardware error or success probability. Diffusion, preparation, routing and error correction are excluded.

The executable audit and all angles are saved in tools/audit_rotation_precision.py and results/rotation-precision-audit-v1.json. Output generation succeeded and prior artifacts were preserved. No new production behavior was introduced. Next evaluate a specified physical or fault-tolerant synthesis model before assigning T-counts or interpreting the logical CX reduction as an end-to-end advantage.
